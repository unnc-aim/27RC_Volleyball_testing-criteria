## 4. 深度模型与误差传播

双目深度由视差计算：

$$
Z = \frac{fB}{d}
$$

对视差误差 $\delta d$ 做一阶近似：

$$
\delta Z \approx \frac{Z^2}{fB}\,\delta d
\quad\Longleftrightarrow\quad
\frac{\delta Z}{Z} = \frac{Z\,\delta d}{fB}
$$

即深度相对误差与距离 $Z$ 成正比、与基线 $B$ 成反比。所有距离相关阈值均按上式换算
（约定 $\delta d_0 = 0.5$ px，换算表见细则文档附录 A）；像素类阈值（重投影 / 极线 /
视差）为绝对值。

## 5. 测试分类（按优先级从高到低）

- **C 类（应用与闭环性能，T01–T04，最高优先级）**：排球检测模型精度、推理速度、
  动态球测距与发球击球闭环；必测项目，不允许 N/A。
- **B 类（环境与系统可靠性，T05–T09）**：默认全测；确不具备条件时可记 N/A
  （归一化规则见细则文档 2.5 节）。
- **A 类（双目标定质量，T10–T19）**：必测项目，不允许 N/A；是 T03 / T04 闭环的
  前提（实施时先于闭环执行），但优先级与权重最低。

## 7. 评分体系摘要

每个定量指标按阈值分四档打分：**优（100）/ 良（80）/ 合格（60）/ 不合格（0）**；
一项测试含多个指标时取最低档（木桶原则）。权重分布为 **C 类 45 / B 类 20 /
A 类 35**（优先级 C > B > A），总分 $S$ 为执行项得分的加权和（归一化至 100 分，
B 类 N/A 自动剔除权重）。完整判据见细则文档第 2 节。

| 等级 | 判定条件 | 结论 |
| --- | --- | --- |
| A（优秀） | S ≥ 90，无否决项，A、C 类无缺测 | 整体质量优秀，可直接交付 |
| B（良好） | 80 ≤ S < 90，无否决项 | 整体质量良好，可交付 |
| C（合格） | 70 ≤ S < 80，无否决项，A、C 类无 0 分项 | 有条件交付，需列出改进项 |
| F（不合格） | S < 70，或触发任一否决项 | 标定不合格，须整改后重新测试 |

**否决项**（触发任一即整体判 F，与总分无关）：

- V1：T10 / T11 重投影 RMS 落在"不合格"档；
- V2：T17 极线误差 RMS 超过合格档（> 0.50 px）；
- V3：T06 触发"标定失效"判据（$\Delta B/B$ 或 $\Delta R$ 任一超合格档）；
- V4：测试过程中出现程序崩溃、无深度输出等致命功能故障。

> 距离类阈值基于参考配置 $B = 1.000$ m、$f = 2200$ px；实际设备须按细则文档附录 A
> 重算后再判分。T03 / T04 的 ground truth 推荐采用侧视 GT 相机（评估结论与布设
> 规范见细则文档附录 F）。
